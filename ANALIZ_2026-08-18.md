## 🔴 BULUNAN HATALAR (Bugs)

### HATA-001: Temp Temizliği Eksik - Sadece User Temp Temizleniyor
- **Durum:** `ClearMemory.ps1` satırında sadece `[System.IO.Path]::GetTempPath()` kullanılıyor
- **Sorun:** README.md ve konsol menüsünde `C:\Windows\Temp` de temizleneceği belirtilmiş ama kodda yok
- **Önem:** Yüksek - Kullanıcı beklentisi karşılanmıyor

### HATA-002: Boş Catch Blokları - Hatalar Yutuluyor
- **Durum:** `Add-Type` ve `ClearAll()` çağrılarındaki tüm try-catch blokları boş
- **Sorun:** Hata oluşursa kullanıcıya hiçbir bilgi verilmiyor, sessizce başarısız oluyor
- **Önem:** Yüksek - Debug imkansız

### HATA-003: Clipboard Komutu Kırılgan
- **Durum:** `cmd /c "echo off | clip"` pipe kullanılıyor
- **Sorun:** Bu komut her Windows sürümünde güvenilir çalışmaz, cmd pipeushing karmaşık
- **Önem:** Düşük - Büyük ihtimalle çalışır ama güvenilmez

### HATA-004: progress_bar 800ms per step
- **Durum:** `Start-Sleep -Milliseconds 40` × 20 karakter = 800ms per adım
- **Sorun:** 4 adım = 3.2 sadece progress bar animasyonu, toplamda ~5-6 saniye kayıp
- **Önem:** Düşük - UX etkisi var ama fonksiyonel değil

### HATA-005: CreateDesktopShortcut.bat `ping` ile bekleme
- **Durum:** `ping -n 3 127.0.0.1 >nul` ile 3 saniye bekleniyor
- **Sorun:** Geleneksel ama portfolio'da kötü görünüyor, `timeout` daha profesyonel
- **Önem:** Kozmetik

### HATA-006: `Out-Null` gereksiz pipeline'da
- **Durum:** `Remove-Item ... | Out-Null` - `Remove-Item` zaten çıktı üretmez
- **Sorun:** Gereksiz kod kalabalığı
- **Önem:** Düşük

## 💡 TEKNİK NOTLAR

- **`NtSetSystemInformation` API:** `SystemInformationClass=80` → `SystemMemoryInformationCommand`
  - `2` = `MemoryFlushModifiedList`
  - `3` = `MemoryPurgeStandbyList`
  - `4` = `MemoryPurgeLowPriorityStandbyList`
- **UAC Elevation:** BAT'te `net session` kontrolü + PowerShell `Start-Process -Verb RunAs`
- **Font Scaling:** `SetCurrentConsoleFontEx` Win32 API ile 16pt Bold Consolas
- **ANSI Desteği:** Windows 10 1607+ varsayılıyor (ANSI escape code desteği)
