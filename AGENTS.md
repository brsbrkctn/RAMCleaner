## 📄 Documentation Guidelines
- **README Language**: All `README.md` files must ALWAYS be written in **English**.
- **No Developer Section**: Do not add an explicit "Developer" or "Geliştirici" section in `README.md` (GitHub automatically displays the author profile).
- **User-Facing Documentation Language**: Implementation plans, task lists, and walkthrough reports intended for the user must be in **Turkish**. Code comments and commit messages remain in **English**.

## 📦 Release & Versioning Policy
- **Semantic Versioning**: Increment version numbers according to semver (Major.Minor.Patch).
- **Changelog**: Maintain and update `CHANGELOG.md` for every release.
